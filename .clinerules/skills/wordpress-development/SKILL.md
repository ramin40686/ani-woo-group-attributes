# WordPress Development

## Purpose
Ensure all WordPress projects generated by Cline follow official coding standards, security practices, and best development principles.

## Active Rule Files
- project-rules.md
- memory-bank.md

## Behavior
- Always apply these rules when generating WordPress plugins or themes.
- Prioritize WordPress Coding Standards (PHPCS) and security practices.
- Enforce modular, production-ready code with no placeholders.
- If requirements are unclear, request clarification instead of assuming.
